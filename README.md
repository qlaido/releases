# Qlaido – Downloads

Hier liegen die Installationsdateien von **Qlaido**, der Windows-App für Beihilfe und private Krankenversicherung.

**Download und Anleitung: [qlaido.de](https://qlaido.de)**

- Neueste Version: [Releases → Latest](https://github.com/qlaido/releases/releases/latest) – dort `Qlaido-Setup-<Version>.exe` herunterladen
- Alle Versionen mit Änderungen: [Releases](https://github.com/qlaido/releases/releases)

## Hinweise

- Qlaido läuft unter Windows 10 und 11 (64 Bit).
- Deine Daten bleiben verschlüsselt auf deinem PC. Ein Update installierst du einfach über die bestehende Version, deine Daten bleiben erhalten.
- Beim ersten Start kann Windows SmartScreen warnen („Der Computer wurde durch Windows geschützt“). Klicke auf **Weitere Informationen → Trotzdem ausführen**.
- Die SHA-256-Prüfsumme jeder Datei steht in der Beschreibung der jeweiligen Version.

Dieses Repository enthält nur die Installationsdateien, keinen Quellcode.
